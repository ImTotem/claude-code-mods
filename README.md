# usage-rail

`세션` 패널([`session-rail`](../../tree/session-rail))에 **사용량** 카드를 넣는 모드입니다. 설정의 사용량 화면을 열지 않아도 남은 한도를 볼 수 있습니다.

- 현재 세션(5시간), 주간 등 API가 알려주는 한도마다 이름, 사용률(%), 막대, 초기화까지 남은 시간을 보여줍니다.
- 컨텍스트 사용량(토큰 / 창 크기)과 세션 비용도 함께 보여줍니다.
- 응답이 끝날 때마다, 그리고 한도가 1%p 움직일 때마다 갱신됩니다. 남은 시간은 30초마다 다시 계산됩니다. **새로고침**을 누르면 바로 다시 불러옵니다.
- 카드 제목(`사용량 ∨`)을 누르면 접히고, 접힌 동안에는 `5시간 43% · 주간 18%` 한 줄만 보입니다.
- `/usage-rail`: `세션` 패널을 열고 수치를 바로 갱신합니다.
- 막대 색: 70% 미만 초록, 70% 이상 노랑, 90% 이상 빨강.
- 카드는 `세션` 패널 맨 위에 놓입니다. 패널을 열고 닫는 방법은 `session-rail`의 README에 있습니다.

한도 정보는 마지막 API 응답이 알려준 값이라 첫 응답 전에는 비어 있고, API 키로 사용할 때는 표시되지 않습니다.

## 설치

```
/plugin install usage-rail --marketplace ImTotem/claude-code-mods
```

`session-rail`이 함께 설치됩니다. 마켓플레이스는 이 저장소의 `main` 브랜치에 있습니다.

## 개발

이 브랜치의 루트가 모드 폴더입니다.

```
claude plugin validate .
claude plugin test .
claude --plugin-dir .
```

`tsconfig.json`은 엔진이 모드를 불러올 때 `.claude-plugin/types/`에 깔아 주는 타입 설정을 이어받습니다. 그 폴더는 커밋하지 않습니다.
