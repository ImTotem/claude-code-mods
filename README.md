# todo-stack

모델이 만드는 할 일을 Claude Code 세션 레일(오른쪽에 붙는 패널)에 요청별로 계속 쌓아 두는 모드입니다. 컨텍스트 압축이나 새 요청 때문에 할 일이 사라지거나 잊히지 않게 하려고 만들었습니다.

- 사용자가 보낸 요청마다 그룹이 하나 생기고, 그 요청 중에 모델이 만든 할 일(TodoWrite, TaskCreate/TaskUpdate)이 그 그룹에 쌓입니다. 최신 요청이 위에 옵니다.
- ☐ 대기 · ◐ 진행 중 · ☑ 완료. 항목을 누르면 완료/미완료가 바뀌고, ✕는 항목이나 그룹을 지웁니다.
- 모델의 목록에서 빠졌는데 끝나지 않은 항목은 `모델 목록에서 빠짐`으로 표시되어 남습니다.
- 직접 누른 완료 표시와 직접 지운 항목은 모델이 다음에 목록을 다시 써도 되돌아오지 않습니다.
- 맨 위 입력칸이나 `/todo-stack <할 일>`로 직접 할 일을 추가할 수 있습니다. 이 항목은 `직접 추가한 할 일` 그룹에 들어갑니다.
- **남은 할 일 프롬프트에 넣기**: 끝나지 않은 할 일 목록을 프롬프트 상자에 넣어 줍니다. 모델에게 다시 알려줄 때 씁니다.
- **완료 숨기기 / 완료 정리 / 모두 지우기**(한 번 더 확인)로 스택을 정리할 수 있습니다.
- 컨텍스트 압축 때 끝나지 않은 할 일을 요약에 그대로 남기라는 지시가 압축 지시에 덧붙습니다. 조직이 Claude Code를 관리하는 환경에서는 사용자가 설치한 플러그인의 압축 훅이 실행되지 않습니다.
- 스택은 세션별로 저장되어(최근 30개 세션) 세션을 이어서 열면 다시 불러옵니다.
- `/todo-stack`: 패널을 다시 엽니다. 패널은 화면이 넓을 때(터미널 전체 화면 기준 144칸 이상) 자동으로 열립니다.

## 설치

```
/plugin install todo-stack --marketplace ImTotem/claude-code-mods
```

마켓플레이스는 이 저장소의 `main` 브랜치에 있고, 이 브랜치(`todo-stack`)를 가리킵니다.

## 개발

이 브랜치의 루트가 모드 폴더입니다.

```
claude plugin validate .
claude plugin test .
claude --plugin-dir .
```

`tsconfig.json`은 엔진이 모드를 불러올 때 `.claude-plugin/types/`에 깔아 주는 타입 설정을 이어받습니다. 그 폴더는 커밋하지 않습니다.
