# usage-rail

Claude Code 세션 레일(오른쪽에 붙는 패널)에 플랜 사용량을 띄우는 모드입니다. 설정의 사용량 화면을 열지 않아도 남은 한도를 볼 수 있습니다.

- 현재 세션(5시간), 주간 등 API가 알려주는 한도마다 막대, 사용률(%), 초기화까지 남은 시간을 보여줍니다.
- 컨텍스트 사용량(토큰 / 창 크기)과 세션 비용도 함께 보여줍니다.
- 응답이 끝날 때마다, 그리고 한도가 1%p 움직일 때마다 갱신됩니다. 남은 시간은 30초마다 다시 계산됩니다. **새로고침** 버튼도 있습니다.
- `/usage-rail`: 패널을 다시 열고 바로 갱신합니다.
- 막대 색: 70% 미만 초록, 70% 이상 노랑, 90% 이상 빨강.

한도 정보는 마지막 API 응답이 알려준 값이라 첫 응답 전에는 비어 있고, API 키로 사용할 때는 표시되지 않습니다.

## 어디에 뜨나요

- **터미널**: 전체 화면 레이아웃(기본값)이면 대화 오른쪽에 세로 패널로 붙습니다(터미널 폭 110칸 이상). 그보다 좁거나 메인 화면 레이아웃(tmux, `CLAUDE_CODE_NO_FLICKER=0`)이면 프롬프트 바로 위에 붙습니다.
- **Claude 데스크톱 앱 · 모바일 앱**: 앱이 패널을 두는 자리에 나옵니다(모바일은 프롬프트 위).
- 두 모드를 함께 쓰면 한 자리에 `사용량` · `할 일` 탭으로 나옵니다.

세션이 시작될 때는 화면 폭이 144칸 이상일 때만 저절로 열립니다(엔진이 요청하지 않은 패널에 두는 기준). 그보다 좁으면 **첫 프롬프트를 보낼 때** 열립니다. 직접 닫으면 그 세션에서는 다시 열지 않고, `/usage-rail`로 다시 열 수 있습니다. 패널을 붙일 수 없는 화면이면 그 이유를 알림으로 한 번 알려줍니다.

## 설치

```
/plugin install usage-rail --marketplace ImTotem/claude-code-mods
```

마켓플레이스는 이 저장소의 `main` 브랜치에 있고, 이 브랜치(`usage-rail`)를 가리킵니다.

## 개발

이 브랜치의 루트가 모드 폴더입니다.

```
claude plugin validate .
claude plugin test .
claude --plugin-dir .
```

`tsconfig.json`은 엔진이 모드를 불러올 때 `.claude-plugin/types/`에 깔아 주는 타입 설정을 이어받습니다. 그 폴더는 커밋하지 않습니다.
