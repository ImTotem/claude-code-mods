# usage-rail

`세션` 패널([`session-rail`](../../tree/session-rail))에 **사용량** 카드를 넣는 모드입니다. Claude 앱의 사용량 카드와 같은 항목·모양으로 보여줍니다.

| 항목 | 오른쪽 | 막대 아래 |
| --- | --- | --- |
| 세션 한도 | `29% 사용됨` | `3시간 54분 후 재설정` (하루가 넘으면 `재설정: (일) 오후 9:00`) |
| 매주 | `4% 사용됨` | `재설정: (일) 오후 9:00` |
| 클라우드 세션 크레딧 | `US$100 중 US$77 남음` | `만료: 11월 5일 오후 4:59 GMT+9` |

- 값은 사용량 화면이 읽는 `/api/oauth/usage`에서 가져옵니다. 세션의 인증은 엔진이 붙여 주고(`$.session.authorize`), 모드는 토큰을 보지 않습니다.
- 그 주소를 읽을 수 없으면(API 키, 게이트웨이 등) 마지막 응답의 한도 헤더 값으로 세션 한도·매주만 보여줍니다. 둘 다 없으면 이유를 한 줄로 보여줍니다.
- **클라우드 세션(claude.ai/code, 데스크톱 앱의 클라우드 세션)에서는 표시되지 않습니다.** 그 세션의 인증에는 이 주소가 요구하는 `user:profile` 권한이 없어 403으로 거절되고, 엔진도 같은 이유로 한도 헤더 값을 넘겨주지 않습니다. 카드는 그 사실을 한 줄로 알려줍니다.
- 세션 시작 때, 응답이 끝날 때마다(1분에 한 번까지), 그리고 5분마다 다시 읽습니다. 남은 시간은 30초마다 다시 계산됩니다.
- 막대는 데스크톱·모바일에서 둥근 막대(SVG), 터미널에서 `━` 줄로 그립니다.
- `/usage-rail`: `세션` 패널을 열고 바로 다시 읽습니다.
- 카드는 `세션` 패널 맨 위에 놓입니다. 패널을 열고 닫는 방법은 `session-rail`의 README에 있습니다.

## 설정

| 설정 | 기본값 | 뜻 |
| --- | --- | --- |
| `timeZone` | `Asia/Seoul` | 재설정·만료 시각을 표시할 IANA 시간대. 클라우드 세션은 UTC로 실행되므로 여기서 정합니다. |

설치할 때 묻고, 나중에는 `/config`에서 바꿀 수 있습니다.

## 설치

```
/plugin install usage-rail --marketplace ImTotem/claude-code-mods
```

`session-rail`이 함께 설치됩니다. 마켓플레이스는 이 저장소의 `main` 브랜치에 있습니다.

## 개발

이 브랜치의 루트가 모드 폴더입니다.

```
claude plugin validate .
claude plugin test .
claude --plugin-dir .
```

`tsconfig.json`은 엔진이 모드를 불러올 때 `.claude-plugin/types/`에 깔아 주는 타입 설정을 이어받습니다. 그 폴더는 커밋하지 않습니다.
