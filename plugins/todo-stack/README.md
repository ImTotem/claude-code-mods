# todo-stack

`세션` 패널([`session-rail`](../../tree/session-rail))에 **할 일** 카드를 넣고, 모델이 만드는 할 일을 하나의 스택으로 계속 쌓아 두는 모드입니다. 컨텍스트 압축이나 새 요청 때문에 할 일이 사라지거나 잊히지 않게 하려고 만들었습니다.

- 요청별로 묶지 않고 할 일만 쌓습니다. 모델이 만든 할 일(TodoWrite, TaskCreate)과 직접 추가한 할 일 모두 새로 생긴 것이 맨 위에 올라갑니다. 모델이 한 번에 만든 목록은 그 순서 그대로 한 덩어리로 위에 올라갑니다.
- 이미 쌓인 할 일은 상태가 바뀌어도 자리를 옮기지 않습니다.
- 할 일 글은 잘리지 않고 줄바꿈됩니다.
- ☐ 대기 · ◐ 진행 중 · ☑ 완료. 표시를 누르면 완료/미완료가 바뀌고, ✕는 그 할 일을 지웁니다. 데스크톱·VS Code에서는 ✕가 마우스를 올린 줄에만 보입니다.
- 모델의 목록에서 빠졌는데 끝나지 않은 항목은 `모델 목록에서 빠짐`으로 표시되어 남습니다. 모델이 만든 할 일은 그 할 일을 만든 세션의 목록만 따라가므로, 다른 세션의 목록이 빼먹었다고 빠짐으로 표시하지 않습니다.
- 이전 세션에서 쌓인 할 일이나 직접 추가한 할 일 중 끝나지 않은 것을 모델이 같은 글로 목록(TodoWrite)이나 TaskCreate에 쓰면, 새로 쌓지 않고 그 할 일을 이어받습니다. 그래서 새 세션의 모델도 이전 할 일의 상태를 바꾸고 완료할 수 있습니다. **남은 할 일 프롬프트에 넣기**로 넣은 글이 그대로 쓰이면 이어받아집니다.
- 직접 누른 완료 표시와 직접 지운 항목은 모델이 다음에 목록을 다시 써도 되돌아오지 않습니다.
- 맨 위 입력칸이나 `/todo-stack <할 일>`로 직접 할 일을 추가할 수 있습니다. 스택 맨 위에 올라갑니다.
- **남은 할 일 프롬프트에 넣기**: 끝나지 않은 할 일 목록을 프롬프트 상자에 넣어 줍니다. 모델에게 다시 알려줄 때 씁니다.
- **완료 숨기기 / 완료 정리 / 모두 지우기**(한 번 더 확인)로 스택을 정리할 수 있습니다.
- 컨텍스트 압축 때 그 세션에서 생긴 끝나지 않은 할 일을 요약에 그대로 남기라는 지시가 압축 지시에 덧붙습니다. 조직이 Claude Code를 관리하는 환경에서는 사용자가 설치한 플러그인의 압축 훅이 실행되지 않습니다.
- **스택은 세션과 상관없이 하나입니다.** 플러그인 저장소(Claude Code 설정 폴더의 `plugins/store/`)에 저장되어 새 세션을 열어도, 플러그인을 새로고침하거나 업데이트해도 그대로 남습니다. 같은 컴퓨터에서 여러 세션을 함께 열어도 같은 스택을 쓰고, 다른 세션에서 바뀐 내용은 10초 안에 보입니다.
- 클라우드 세션(claude.ai/code, 앱의 클라우드 세션)은 세션마다 컨테이너가 따로라서 저장소도 세션마다 따로입니다. 한 클라우드 세션 안에서는 새로고침해도 남지만, 다른 클라우드 세션과는 공유되지 않습니다.
- 세션별로 저장하던 이전 버전의 스택은 처음 실행할 때 하나로 합칩니다(최근에 쓴 세션의 할 일이 위). 요청별로 묶여 있던 것도 묶음을 풀어 합칩니다. Claude Code는 디스크에 있던 버전으로 먼저 시작하고 업데이트를 그 뒤에 받기 때문에, 이전 버전이 잠깐 실행되며 따로 저장한 할 일도 다음에 읽을 때 위에 합칩니다.
- 카드 제목(`할 일 ∨`)을 누르면 접히고, 접힌 동안에는 남은 개수만 보입니다.
- `/todo-stack`: `세션` 패널을 엽니다. `/todo-stack <할 일>`은 할 일을 추가하고 패널을 엽니다.
- 카드는 `세션` 패널에서 사용량 카드 아래에 놓입니다. 패널을 열고 닫는 방법은 `session-rail`의 README에 있습니다.

## 설치

```
/plugin install todo-stack --marketplace ImTotem/claude-code-mods
```

`session-rail`이 함께 설치됩니다. 마켓플레이스는 이 저장소의 `main` 브랜치에 있습니다.

## 개발

이 브랜치의 루트가 모드 폴더입니다.

```
claude plugin validate .
claude plugin test .
claude --plugin-dir .
```

`tsconfig.json`은 엔진이 모드를 불러올 때 `.claude-plugin/types/`에 깔아 주는 타입 설정을 이어받습니다. 그 폴더는 커밋하지 않습니다.
